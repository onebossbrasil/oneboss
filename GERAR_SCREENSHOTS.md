# 📸 Gerar Screenshots - 3 Métodos Rápidos

## ✅ OBRIGATÓRIO: Mínimo 2 screenshots de 1080x1920 px

---

## 🌐 MÉTODO 1: Mockups Online (MAIS RÁPIDO - 5 minutos)

### Passo 1: Acessar o site
👉 **https://mockuphone.com/**

### Passo 2: Escolher dispositivo
- Selecione: **Android**
- Escolha: **Samsung Galaxy S23** ou similar
- Orientação: **Portrait** (vertical)

### Passo 3: Upload das imagens
Você precisa de capturas de tela do site OneBoss. Tire screenshots das seguintes telas:

**Sugestões de telas para capturar:**
1. **Página inicial** - Produtos em destaque
2. **Detalhes do produto** - Galeria de imagens
3. **Catálogo/Loja** - Lista de produtos (opcional)
4. **Tela de login** - Visual elegante (opcional)

**Como tirar screenshots do site:**
1. Abrir: http://localhost:8081 (ou seu site publicado)
2. Abrir DevTools (F12)
3. Clicar no ícone de "Toggle device toolbar" (Ctrl+Shift+M)
4. Selecionar: **Pixel 5** ou **iPhone 12 Pro**
5. Ajustar para 1080x1920 px
6. Navegar pelas telas
7. Tirar screenshot de cada tela (Ctrl+Shift+P → "Capture screenshot")

### Passo 4: Gerar mockups
1. Fazer upload das screenshots no Mockuphone
2. Baixar as imagens geradas
3. Salvar como: `screenshot-1.png`, `screenshot-2.png`, etc.

### Alternativa: Screenshots puras (sem moldura)
Se preferir screenshots sem moldura de celular:
1. Tire as screenshots conforme acima
2. Salve diretamente (não precisa do Mockuphone)
3. Verifique que tem 1080x1920 px

## 🖥️ MÉTODO 2: Usando seu próprio site (3 minutos)

Se seu site já está online (ex: oneboss.com.br):

### Passo 1: Abrir site em modo mobile
1. Abrir Chrome/Edge
2. Acessar seu site
3. Pressionar F12 (DevTools)
4. Clicar no ícone do celular (Ctrl+Shift+M)

### Passo 2: Configurar resolução
1. Selecionar: **Responsive**
2. Definir: **1080 x 1920**
3. Zoom: 100%

### Passo 3: Navegar e capturar
1. Navegar para cada tela importante:
   - Página inicial
   - Produto específico
   - Catálogo
   - Login (opcional)

2. Para cada tela, tirar screenshot:
   - **Ctrl+Shift+P**
   - Digitar: "Capture screenshot"
   - Selecionar: "Capture full size screenshot"
   - OU usar Windows Snipping Tool (Win+Shift+S)

### Passo 4: Salvar
- Nome: `screenshot-1.png`, `screenshot-2.png`, etc.
- Local: `C:\Users\inaci\Desktop\`

## 📱 MÉTODO 3: Emulador Android (10-15 minutos)

**Requer: Android Studio instalado**

### Passo 1: Instalar Android Studio
Se ainda não tem:
- Download: https://developer.android.com/studio
- Instalar (3-5 GB)

### Passo 2: Iniciar emulador
```bash
cd C:\Users\inaci\Desktop\Cursor\OneBoss
npx cap open android
```

1. Android Studio vai abrir
2. Menu: **Tools → AVD Manager**
3. Clicar: **Create Virtual Device**
4. Escolher: **Pixel 5** ou **Pixel 6**
5. System Image: **Android 13 (Tiramisu)**
6. Finish
7. Clicar no ▶️ (Play) para iniciar

### Passo 3: Instalar app no emulador
No Android Studio:
1. Clicar no ▶️ verde (Run)
2. Selecionar o emulador
3. Aguardar instalação (~1 minuto)

### Passo 4: Tirar screenshots
No emulador:
1. Navegar pelas telas do app
2. Para cada tela, clicar no ícone 📷 (Camera) na barra lateral
3. Ou pressionar: **Ctrl + S**
4. Screenshots salvos em: `C:\Users\inaci\Pictures\`

### Passo 5: Verificar dimensões
- Botão direito no arquivo → Propriedades → Detalhes
- Deve ser 1080x1920 ou similar
- Se não for, redimensionar em: https://www.iloveimg.com/resize-image

## ✅ REQUISITOS DOS SCREENSHOTS:

### Play Console exige:
- ✅ **Formato:** PNG ou JPG
- ✅ **Dimensões:** 1080x1920 px (ou 9:16 ratio)
- ✅ **Quantidade:** Mínimo 2, máximo 8
- ✅ **Tamanho:** Máximo 8 MB cada
- ❌ **Sem:** Bordas de dispositivo exageradas
- ❌ **Sem:** Conteúdo pornográfico, violento ou inadequado

### Dicas de qualidade:
- ✅ Alta resolução
- ✅ Cores vibrantes
- ✅ Texto legível
- ✅ Interface limpa (sem erros de UI)
- ✅ Conteúdo real (produtos de verdade)
