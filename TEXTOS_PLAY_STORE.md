## 📊 Dados de Segurança (Data Safety)

### Dados Coletados:
```
✓ Informações pessoais (nome, e-mail, telefone, estado)
✓ Atividade no app (produtos visualizados, favoritos, buscas)
✓ ID do dispositivo (para analytics)
```

### Finalidade:
```
• Autenticação e gerenciamento de conta
• Personalização da experiência
• Comunicação com usuários (notificações, suporte)
• Analytics e melhorias do app
• Contato com vendedores (WhatsApp)
```

### Segurança:
```
✓ Dados criptografados em trânsito (HTTPS/SSL)
✓ Dados criptografados em repouso (banco de dados)
✓ Usuários podem solicitar exclusão de dados
✓ Conformidade com LGPD (Lei Geral de Proteção de Dados)
✓ Não compartilhamos dados com terceiros sem consentimento
```

### Permissões Necessárias:
```
• INTERNET - Para acesso à API e conteúdo
• ACCESS_NETWORK_STATE - Para verificar conectividade
• CAMERA (opcional) - Para tirar fotos de produtos
• READ_EXTERNAL_STORAGE (opcional) - Para selecionar imagens
```
